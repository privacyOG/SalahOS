# SalahOS branding

The canonical SalahOS icon source is `artwork/salahos-icon-source.jpg`, supplied by the project owner and maintained by privacyOG.

Generated Web/PWA, Android, and iOS icon assets are derived from that canonical source and verified by `scripts/generate_pwa_icons.py --check`.

Do not replace the canonical source or generated platform assets with generic placeholder artwork. When the canonical source changes, regenerate and validate all platform icon assets together.
